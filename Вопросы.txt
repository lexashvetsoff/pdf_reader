Дополнения:

    Факт отпускная цена без НДС, с НДС и дата реализации одной строокой
    - При proizv_price_and_sale_date_one_line == True: 
        "column_price_proizv_no_nds" - заполняем номер колонки
        "column_price_proizv_s_nds" - должен быть null
        "column_sale_date_proizv" - должен быть null
    
    Отпускная цена оптовой организации одной строокой
    - opt_price_one_line == True
        "column_opt_price_no_nds": заполняем номер колонки
        "column_opt_price_s_nds": должен быть null
    
    - remove_shift_tail_if_one_page (убрать сдвиг в конце если одна страница)

    - check_headings_on_every_page (проверять заголовки на каждой странице)
        есть такие поставщики которые то укажут заголовок на странице, то не укажут (например Биннофарм в реестрах)
        при True параметр headings_on_every_page должен быть False
    
    - table_shift_control (контроль сдвига таблицы)
        у некоторых поставщиков некоторые таблицы смещаются на один столбец
    
    - three_copies_in_one_file (три экземпляра в одном файле)
        например Сотекс - один файл pdf содержит три одинаковых таблицы
